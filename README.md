# Шлагбаум.Путь

Неофициальный сервис сопровождения городской программы установки шлагбаумов в **Москве** (АМПП / transport.mos.ru / «Электронный дом»).

## Что умеет сейчас

- Лендинг в стилистике госуслуг-портала
- Ограничение «только Москва»
- Кабинет инициатора (localStorage): кейс дома, этапы, генерация писем, отметка «отправлено → ждём ответ»
- Тарифы частной консультации

## Чего нет (намеренно)

- Это **не** официальный сайт АМПП / НТУ / mos.ru
- Нет автоотправки в личные кабинеты города без авторизации пользователя
- Нет покрытия регионов вне Москвы

## Локальный запуск

Откройте `index.html` в браузере или:

```bash
npx --yes serve .
```
